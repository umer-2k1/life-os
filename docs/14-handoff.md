## Stack (final)

- **Next.js 16** (App Router, TS strict), **Tailwind 4**, hand-built shadcn-style primitives.
- **Postgres** via **TypeORM** (Supabase in production). No SQLite fallback.
- **Auth:** single-user **6-digit PIN** (scrypt hash, signed httpOnly cookie). Default `252525`, changeable in Settings.
- **AI:** Groq (`openai/gpt-oss-120b`) → OpenRouter free models → optional Grok/DeepSeek. Deterministic heuristic fallback when no key.
- **Voice:** Groq Whisper (`whisper-large-v3`).
- **Images:** Cloudinary (Supabase Storage fallback).
- **Email:** Resend.
- **Scheduler:** GitHub Actions hourly → `/api/cron/check-ins`.
- **MCP:** Streamable HTTP at `/api/mcp`.

## Run it

```bash
pnpm install
pnpm db:migrate       # creates/migrates Supabase schema
pnpm db:seed          # 8 starter dreams (idempotent)
pnpm dev              # http://localhost:3000
```

Login: the PIN in `.env` is only the default (`252525`) until changed in Settings.

- PIN login + session cookie + route protection.
- Dashboard renders live Supabase data.
- Dream create/detail/gallery upload to Cloudinary.

- Reports: generated weekly report + PDF download.
- MCP: initialize + tools/list returned 29 tools.
- Cron: `POST /api/cron/check-ins` returns state.

## Known gaps

- **Telegram cannot be reached from this dev machine** (network blocks `api.telegram.org`). Deployed on Vercel it will work; use Settings → Register webhook.
- Web push notifications are not implemented (Telegram + PWA offline only).
- Report trajectory is a conservative estimate (1 on-track action ≈ 1% velocity); document says "estimate".
- Follow-up questions are generated by AI but the UI does not yet render a follow-up thread.
- No automated tests yet.
- `OWNER_EMAIL` must be set for emailed reports.
