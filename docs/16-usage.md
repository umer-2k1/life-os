# 16 · Daily use

## The loop (what actually changes behavior)

1. **Midnight** — the bot asks: *"Day N. What did you do today toward the money / the dreams? Voice or text."*
2. You send **one voice note** (or text). That is the only required effort.
3. The AI splits it into activities, marks each 🟢 / 🟡 / 🔴, prices waste in **days added**, and gives a score.
4. You get a ≤5-bullet recap + one **Next** action.
5. If you ignore it, it re-asks every 6 hours until you answer on **any** channel.

## Where to answer

- **Telegram** — best. Voice notes are transcribed.
- **Website → Activity → Log this day** — text box.
- **MCP / Claude** — “Log my day: …” (tools `get_pending_checkin`, `answer_checkin`).

The first answer closes the check-in everywhere.

## The website

| Tab | What it's for |
|---|---|
| **Dashboard** | North Star, today's score, streak, priorities, recap, heatmap, why-you-started |
| **Dreams** | The emotional heart. Tap a card for the why, milestones, savings, gallery |
| **Activity** | Kanban board for any date. Drag cards between Today / Doing / Done / Wasted |
| **Reports** | Weekly/monthly/custom verdict + PDF |
| **Settings** | North Star, identity, PIN, AI keys, check-in schedule, Telegram webhook |

## Weekly ritual (5 minutes)

1. Open **Reports** → **This week**.
2. Read the trajectory: which dream is **stalled**.
3. Read **Fix one thing**. Do that tomorrow.
4. Open the stalled dream → set its **next action** (or ask the bot).

## Changing your PIN

Settings → Security → current PIN + new PIN + confirm. 6 digits exactly.
Eight wrong attempts in 10 minutes locks login temporarily.

## Adding a dream

Dreams → **Add dream**. Only the title is required. Add the raw **why** immediately —
that is what the system resurfaces when you want to quit.

## Money

Per dream: target, saved, remaining, %. Add a saving from the dream sheet.
The dashboard North Star is your own number in Settings.
